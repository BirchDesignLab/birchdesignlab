# Proof a4: cottagecore, several hands and the Fraunces wetness by role (items 1, 17)

Shared rules: `a-common.md`. Task name for paths: `cc-hands`.

**Question.** Do three hand roles drawn from Caveat Variable's 400 to 700
axis read as three different writers on Home, Services and Contact (brief
item 1, tell 2), and do three Fraunces SOFT/WONK settings read as three
wetnesses (item 17), in both schemes, with every new ink passing contrast?

**Make.**
- Proof CSS defining `--hand-kicker`, `--hand-note`, `--hand-label` (each:
  weight, ink, size step, tilt) as the brief sets them: kicker about 650,
  rose-deep light / amber dark, -1.5deg; margin note about 450, sepia from
  the ink-brown family, a touch larger, +1deg; label about 400, sage-dark
  light / sage-light dark, upright. Applied to the selectors the brief
  names (kickers, "How we build", "Visit the lab", back links, footer
  location, form labels, № numerals, specimen labels; the mobile nav takes
  the margin-note voice). No second script font.
- Fraunces: SOFT 100 for the billboard "Birch", "Sent." and the wordmark;
  SOFT about 50 for h2 sheet titles; SOFT 0 to 20 with WONK 0 for card h3s.
  The italic pull quotes: show SuperSoft and Sharp, pick one by eye against
  the billboard.
- Contrast: every new ink against `--paper`, `--note` and `--field` in both
  schemes, numbers in the write-up and as `meta.contrast` entries ready to
  paste.

**Capture.** Home, Services, Contact and About at 1440, 820 and 390, both
schemes, before and after; crops of the kicker, a margin note and a label
side by side.

**Answer to give.** The CSS block, the contrast entries, the pull-quote
pick, and the founder sheet.
