## Traps worth carrying

- **A theme toggle that appears not to repaint is probably the preview pane.**
  It does not composite frames, so a transitioned property never advances and
  `getComputedStyle` returns the old value forever. Reproduces on `main` with
  any change stashed; disabling transitions makes the new value apply instantly.
  `bdl-002/Experiment.astro` hit a related problem in a real browser and worked
  around it with `transition: none`, so do not assume it is always the pane.
- **The Claude Design exporter drops CSS.** Exported SVGs keep paths, gradients,
  masks, clip paths and class hooks, but the keyframes and the `animation`
  bindings live in the review sheet's `<head>` and do not travel. It also leaves
  wordmarks as live `<text>`, which falls back to a generic serif everywhere the
  font is not installed. Both are properties of the exporter, confirmed against
  two byte-identical exports, so **re-run both scripts after every re-export**.
- **Do not bulk-edit files with PowerShell `Get-Content -Raw`.** It reads UTF-8
  as ANSI, and writing back double-encodes every non-ASCII character. It
  corrupted two files mid-session before a scan caught it. Use the editing tools,
  or `[System.IO.File]::ReadAllBytes` with an explicit UTF-8 decode.
- **Another session may be live in the same working tree.** One was, in the C&C
  repo, and a branch created here switched it out from under that session; its
  next broad `git add` swept an unrelated plan into a caller-deck commit and
  pushed it. Check `git status` and `git log -1` before branching or committing
  in a repo this session does not own.
