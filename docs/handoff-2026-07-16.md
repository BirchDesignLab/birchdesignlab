## 2. Decisions locked (do not relitigate casually)

- **Palette** (4 styleguide rounds): dark face = warm charcoal `#1c1a17`, warm bark mark `#f4f0e6`, muted `#a89f8f`, moss accent `#a3bd8f`, caramel accent-strong `#bf9468`. Light face = warm limestone `#f5f1e8`, ink `#1f1b15`, muted `#5a5244`, forest accent `#2b4a37`, leather accent-strong `#4a3a2c`. Faces intentionally asymmetric. All AA.
- **Type:** Marcellus for display and smallcaps (uppercase engraved caps), Spectral body at 18px.
- **Bark:** alpha tokens `--bark-alpha-lo: 0.03` / `--bark-alpha-hi: 0.69`, both themes. Seed strategy: by date (the site grows a new tree daily); confirmed. Depth parallax on scroll plus visible breathing.
- **Home hero:** billboard. Wordmark only, centered on desktop, word-per-line on mobile, own tokens (`--font-billboard`, `--billboard-weight`, `--billboard-color`).
- **Writing rules:** no emdashes anywhere, ever (AI flag). Human voice. Birch talk confined to About. The old credo ("first green after the fire") is dead. "Software and websites", never the reverse. "Designed, constructed, and cared for." Title separators are middots.
- **Accessibility policy:** core site holds WCAG AA; Lab experiments are exempt by design, with the specimen plate as each piece's accessible fallback.
- **Lab numbering:** BDL-001 Bark Engine, BDL-002 The Styleguide, BDL-003 Novgorod Letters (forthcoming), BDL-004 reserved for the view-source CSS feat.
- **Tooling model:** `/styleguide` is the founder's full instrument; `/lab/bdl-002` is the public curated room. Controls graduate from instrument to room as they prove interesting. Internal tools get kept and catalogued for client-site reuse.

## 5. How to work on it

```
npm run dev        # local site at localhost:4321
npm test           # 26 unit tests (bark math, schema, color math)
npm run check      # astro typecheck
npm run build      # static build to dist/
git push           # deploys production via Cloudflare Pages
```

The fiddle loop: open `/styleguide`, switch candidates, watch the live contrast ratios, hit Copy tokens when something screams, hand the block to Claude to lock into `src/styles/tokens.css`. Adding a Lab experiment: one markdown file in `src/content/lab/`, one component folder in `src/experiments/`, one registry line.
