# The locked marks

The Birch Design Lab mark, locked 2026-08-13 out of a Claude Design round run
against [`docs/brand-brief.md`](../../../docs/brand-brief.md). The outcome, and
what is still open, is at the foot of that brief.

The mark: a vertical stem with two chevron branches, drawn twice at a 12px
offset so the strokes overlap. One stroke neutral, one canopy green `#2f6644`.
Night is warm stone `#a89f8f` blended `screen` on charcoal; day is leather
`#4a3a2c` blended `multiply` on paper. Same geometry everywhere.

## What is in here, and which copy to reach for

**`Birch Design Lab logo brief.zip`** — the delivery exactly as Claude Design
produced it. Untouched, and it stays that way. If a question ever comes up about
what was actually handed over, this is the answer. Do not edit it, and do not
delete it because `files/` looks like a duplicate.

**`files/`** — the same SVGs as working copies. Identical to the zip except that
the animated ones now carry an inlined `<style>` (see below). These are the ones
to use and to point code at.

**`png/`** — rasterised copies of the static set for the places that refuse SVG:
manifest icons, OG cards, social avatars, print and upload paths. Generated by
`scripts/brand/rasterize-logos.mjs`; never hand-edit them.

## The numbered groups

| Group | What it is |
|---|---|
| `8a`–`8h` | The static locked set: mark alone, system sheet (stacked + horizontal), favicon cut, rug, seams, echo, tile. Night and day where it applies. |
| `9e`–`9h` | Animated: settle, pass, drawn and breathing, flip. |
| `10d`, `10f`, `10g` | Animated: signature lockups (stacked + horizontal), lacquer sheen, crossing. |
| `11a`–`11d`, `12a`–`12d` | Direct exports that are **not** in `Locked Marks.dc.html`. They are perfectly good static marks; what they lack is any recoverable animation, because the review sheet carries no bindings for them. Four of them (`11a`, `12b`, `12c`, `12d`) are filter-based and parked for a later look. |

`Locked Marks.dc.html` is the review sheet. It renders every kept mark and is
still the best way to look at the set. Note that its copies of the SVGs carry
their animation as inline `style` attributes, which is why the exported files
needed the fix below.

## Why the animated files were edited

The export kept every path, gradient, mask, clip path and class hook, but the
CSS stayed behind in the sheet's `<head>`. The standalone files were therefore
static marks with hooks that nothing bound to.

`scripts/brand/inline-logo-animations.mjs` injects each file's keyframes, its
hook bindings, and a `prefers-reduced-motion` guard. After that they animate on
their own in an `<img>`, as a CSS background, or inlined.

**Timing lives in that script's `MARKS` table**, one number per mark: settle 9s,
pass 13s, drawn 11s with a −1.2s trail on the second stroke, flip 16s, signature
14s with a −0.9s trail and the wordmark rising on the same beat, lacquer 9s,
crossing 18s. Edit and re-run.

It is a script rather than a hand edit because a re-export drops the bindings
again, and a re-export is expected.

## Checking a re-export

Verified 2026-08-13: a second export pulled straight from Claude Design was
**byte-identical to the zip across all 33 files**, and carried no animation
either. So the missing CSS is how the exporter behaves, not a bad download, and
the inlining step above is a permanent part of the pipeline rather than a
one-time repair.

When the next export arrives, compare it against the zip before replacing
anything. `files/` should differ from a fresh export in exactly the 11 animated
marks and nowhere else; anything else that moved is a real upstream change worth
looking at.

```powershell
Add-Type -AssemblyName System.IO.Compression.FileSystem
$zip = [System.IO.Compression.ZipFile]::OpenRead("assets/brand/logos/Birch Design Lab logo brief.zip")
foreach ($e in $zip.Entries) { if ($e.Name) { $s = $e.Open(); $ms = New-Object System.IO.MemoryStream; $s.CopyTo($ms); $s.Close()
  $old = [BitConverter]::ToString([System.Security.Cryptography.SHA256]::Create().ComputeHash($ms.ToArray()))
  $new = [BitConverter]::ToString([System.Security.Cryptography.SHA256]::Create().ComputeHash([IO.File]::ReadAllBytes("<new-export>/$($e.Name)")))
  if ($old -ne $new) { "changed: $($e.Name)" } } }
$zip.Dispose()
```
